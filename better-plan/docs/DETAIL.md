# Better Plan

A two-phase agent discipline with a right-sidebar decision panel.

1. **Asking**: the agent explores the design tree and publishes each question to the panel with clickable options. The recommended option is pre-checked, so one click settles it; "Other answer…" is there only when you have a different idea.
2. **Plan**: once every question is settled, the agent publishes an ordered plan. Each step is confirmed with one click, or given a custom answer.

Nothing is asked in the chat: every question and every plan choice lives on the panel.

The chat-input icon turns the feature on and off (blue when on, grey when off). Right-click it to open the panel; the panel also opens itself once whenever a new batch of items awaits you. All rules are vendored into the plugin and do not change with skill updates.
